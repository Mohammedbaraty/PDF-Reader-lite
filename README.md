# PDF Reader

یک PDF خوان سریع، سبک و کاربردی برای اندروید.

## ✨ امکانات
- نمایش تمام صفحات PDF با کیفیت بالا
- قابلیت زوم و جابه‌جایی روی صفحات
- حالت شب و روز
- نوار پیمایش (SeekBar) برای رفتن سریع به صفحات
- منوی پرش به صفحه خاص
- اشتراک‌گذاری فایل PDF
